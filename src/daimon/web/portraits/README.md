# Portraits

The About section shows an illustrated **medallion** for each philosopher by
default (rendered in the browser — copyright-free, no files needed).

## Want real photographs instead?
Drop an image here named by the philosopher's key and the app will use it
automatically (it prefers a real image and falls back to the medallion):

```
seneca.jpg     aurelius.jpg     nietzsche.jpg     camus.jpg     weil.jpg
```
(`.jpg`, `.png`, or `.webp` all work. ~600x600, square, looks best.)

## Licensing — read before adding images
- **Seneca, Marcus Aurelius, Nietzsche** — public-domain images exist on
  Wikimedia Commons (ancient busts/statues; for Nietzsche, pre-1929 photographs).
  Safe to use. Keep the file/credit if the source asks.
- **Camus (d. 1960) and Weil (d. 1943)** — most photographs of them are STILL
  UNDER COPYRIGHT (the photographer's rights). Do **not** drop in a random web
  image. Either keep the illustrated medallion, or use an image you have a clear
  licence for.

When in doubt, leave it as the medallion — it's tasteful and risk-free.
