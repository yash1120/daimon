# Daimon

**Daily letters from the philosophers — grounded in their own words.**

> Deploying this publicly? See [DEPLOY.md](DEPLOY.md) — it's a one-file Docker app (multi-user + rate-limited) ready for Hugging Face Spaces.

Daimon is an agentic correspondence. Each day a philosopher — Seneca, Marcus Aurelius, Nietzsche, Camus, or Simone Weil — writes you a short letter. You reply when you feel like it. You can also gather them all into a **salon** and put a single question to the room. Over weeks, a graph of the themes your own thinking keeps circling back to begins to surface.

Named for the *daimonion*, the inner guiding voice Socrates said spoke to him — and a quiet pun on a background *daemon*, since Daimon can run as a scheduled job that writes to you each morning.

Free to run: letters are generated by [Groq](https://console.groq.com)'s free, very fast LLM API.

## Quick start

```bash
pip install -e .
cp .env.example .env          # then paste your free Groq key into .env
daimon init
daimon write                  # a letter arrives in your terminal
```

Prefer the browser? `daimon web` → open http://127.0.0.1:8000

> No Groq key yet? The web UI still works — `/api/generate` and `/api/salon` fall back to bundled samples so you can see the whole experience before signing up.

## What you can do

| Command | What it does |
|---|---|
| `daimon init` | Create the local SQLite store. |
| `daimon write [-p seneca]` | Generate today's letter from a philosopher. |
| `daimon reply [-p seneca]` | Write back; your reply shapes the next letter. |
| `daimon log [-p seneca]` | Read your correspondence so far. |
| `daimon web` | Launch the enhanced 3D web reading experience (FastAPI). |
| `daimon salon "<question>" [-p seneca,nietzsche]` | Pose one question to several philosophers at once. |
| `daimon themes [-p seneca] [--open]` | Build a graph of the recurring concepts in *your* replies. |
| `daimon send [-p seneca] [--dry-run]` | Generate today's letter and email it (Resend). |

**Philosophers:** `seneca` · `aurelius` · `nietzsche` · `camus` · `weil`

## The web experience

`daimon web` serves a single-page reading app built for stillness and depth — vanilla JS + Three.js + GSAP over FastAPI, no build step.

- **3D background.** A slow-drifting field of ink-motes, a sparse constellation/orrery, and a faint gold **wireframe dodecahedron** (Plato's solid for the cosmos) turning in the deep, all reacting to the cursor with eased parallax.
- **Transitions.** Moving between views (hero · reading · salon · timeline) plays a brief directional "ink-wash" sweep, so navigation feels like turning a page.
- **The letter.** Presented on a warm parchment card on a dark "ink" desk — Playfair Display headings, Libre Baskerville prose, a Greek-key meander divider and a wax-seal motif.
- **Salon view.** Ask the room a question and watch the philosophers answer on a fan of cards, each with its own sigil and accent.
- **Honours `prefers-reduced-motion`** (the 3D freezes, transitions become simple fades) and is responsive to mobile.

## How it works (the agentic part)

Each letter is produced by a small [LangGraph](https://langchain-ai.github.io/langgraph/) state machine:

```
load_context → planner → drafter → polisher
```

1. **load_context** — pulls recent correspondence and any reply you've written since the last letter.
2. **planner** — decides the *kind* of letter: an opening, a response to your reply, or a fresh provocation if you've gone quiet.
3. **drafter** — writes in the philosopher's voice, grounded by **RAG**: it retrieves passages from the philosopher's own corpus and lets them steep the letter's themes and imagery.
4. **polisher** — light cleanup of formatting.

**Salon mode** (`daimon salon` / `POST /api/salon`) runs a parallel fan-out instead: each selected philosopher answers the same question independently and concurrently, each grounded in their own corpus, each in their own voice.

### RAG + the corpora
Retrieval defaults to **chroma** vector search (a small embedding model is fetched once on first use, then cached); set `DAIMON_RAG_BACKEND=tfidf` for an instant, offline scikit-learn backend instead. The code falls back to TF-IDF automatically if chroma can't initialise.

The corpora live in `rag/corpus/`. Seneca, Marcus Aurelius, and Nietzsche use genuine **public-domain** passages (Gummere, Long, Common/Zimmern/Ludovici translations). Camus and Weil remain under copyright, so their files contain **original thematic notes** (paraphrased concept summaries, *not* quotations) — enough to ground voice and ideas without reproducing protected text.

### Theme graph
`daimon themes` mines your *replies* for recurring philosophical concepts (a curated lexicon by default; `--llm` for model-based extraction), builds a **networkx** co-occurrence graph, and renders it as an interactive [pyvis](https://pyvis.readthedocs.io/) page. `--neo4j` additionally mirrors the graph into Neo4j (`pip install neo4j`, set `NEO4J_*`).

### Daily delivery
`daimon send` (or `python -m daimon.delivery.daily`) generates and emails the day's letter via [Resend](https://resend.com). A GitHub Actions workflow (`.github/workflows/daily-letter.yml`) runs it on a daily cron — set `GROQ_API_KEY`, `RESEND_API_KEY`, and `DAIMON_TO_EMAIL` as repo secrets. (CI storage is ephemeral, so the scheduled job delivers letters but doesn't retain history between runs — run locally for a persistent correspondence.)

## Architecture

```
src/daimon/
  cli.py              # init / write / reply / log / web / salon / themes / send
  graph.py            # LangGraph: load_context → planner → drafter(+RAG) → polisher
  salon.py            # parallel fan-out: many philosophers, one question
  llm.py              # Groq (ChatGroq) client
  db.py               # SQLite store for letters + replies
  config.py           # .env loading
  personas/           # seneca, aurelius, nietzsche, camus, weil (+ registry)
  prompts/            # each philosopher's system prompt
  rag/                # retrieval over corpora (chroma | tfidf)
    corpus/           # seneca, aurelius, nietzsche (public domain); camus, weil (thematic notes)
  themes/             # concept extraction → networkx graph → pyvis viz (+ Neo4j)
  delivery/           # Resend email + daily cron entrypoint
  api.py              # FastAPI app (letters, reply, salon)
  web/                # index.html, styles.css, app.js, three-bg.js, salon.js
.github/workflows/
  daily-letter.yml    # scheduled daily delivery
```

**Stack:** Python · LangGraph · Groq · FastAPI · Three.js + GSAP · SQLite · chromadb / scikit-learn · networkx / pyvis / Neo4j · Resend · GitHub Actions.
