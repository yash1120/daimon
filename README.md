# Daimon

**Daily letters from the philosophers — grounded in their own words.**

Daimon is an agentic correspondence with history's great thinkers. Each day a philosopher — **Seneca, Marcus Aurelius, Nietzsche, Camus, or Simone Weil** — writes you a short letter. You reply when you feel like it. You can gather them into a **salon** and put one question to the room, ask them to write on a **topic**, and watch a quiet map of **your own philosophy** take shape from the things you keep coming back to.

Named for the *daimonion*, the inner voice Socrates said spoke to him — and a quiet pun on a background *daemon*, since Daimon can also run as a scheduled job that writes to you each morning.

Built entirely on free tiers. Letters are generated by [Groq](https://console.groq.com)'s fast, free LLM API.

## Features

**The correspondence**
- ✍️ **Daily letters** written in each philosopher's distinct voice
- 💬 **Reply** — your replies shape the next letter
- 🏛️ **Salon mode** — pose one question and several philosophers answer together, in parallel
- 🎯 **Topic requests** — ask a philosopher to write to you about anything
- 📖 **Further reading** — every letter surfaces the real passages from their works that grounded it (RAG, made visible)

**Your space (private to each visitor)**
- 🔖 **Bookmarks** — star letters and keep them in a Saved view
- 🔍 **Search** across your whole correspondence
- 📊 **Stats & reading streak** — letters, replies, active days, per-philosopher breakdown
- 🌌 **"Your philosophy"** — a living constellation of the concepts your replies keep circling
- 🔊 **Read-aloud** (text-to-speech) · 🌗 **light / dark theme** · ⚙️ **settings** (name, default philosopher)
- 🖼️ **Share a letter** as an image card · 📲 **installable PWA** (works offline) · first-visit **onboarding**

**Under the hood**
- 👥 **Multi-user** by anonymous session cookie — everyone has their own private correspondence, no login
- 🛡️ **Rate-limited** to protect the shared API key
- 📨 **Daily email** delivery (Resend) on a GitHub Actions cron
- 🕸️ **Theme graph** of your replies (networkx / pyvis, optional Neo4j export)
- ✅ **Tests (pytest) + CI** (GitHub Actions)

## Quick start

```bash
pip install -e .
cp .env.example .env          # paste your free Groq key into .env
daimon init
daimon write                  # a letter arrives in your terminal
```

Prefer the browser? `daimon web` → open http://127.0.0.1:8000

> No Groq key yet? The web UI still works — generation and salon fall back to bundled samples, so you can explore the whole experience before signing up.

## The web experience

`daimon web` serves a single-page reading app built for stillness — vanilla JS + Three.js + GSAP over FastAPI, no build step:

- A slow-drifting field of ink-motes, a sparse constellation, and a faint gold **wireframe dodecahedron** (Plato's solid for the cosmos) turning in the deep.
- Letters presented on a warm **parchment** card; directional **ink-wash** transitions between views.
- Views: hero · reading · salon · timeline · your philosophy · about · saved · stats.
- Honours `prefers-reduced-motion`, responsive to mobile, light + dark themes.

## How it works (the agentic part)

Each letter is produced by a small [LangGraph](https://langchain-ai.github.io/langgraph/) state machine:

```
load_context → planner → drafter (+RAG) → polisher
```

1. **load_context** — pulls the visitor's recent correspondence and any new reply.
2. **planner** — picks the kind of letter (opening / response / provocation / a requested topic).
3. **drafter** — writes in the philosopher's voice, grounded by **RAG**: it retrieves passages from the philosopher's own corpus and lets them steep the letter (those passages are also returned as "further reading").
4. **polisher** — light formatting cleanup.

**Salon mode** fans out instead: each chosen philosopher answers the same question independently and in parallel, each grounded in their own corpus.

### RAG & the corpora
Retrieval defaults to **chroma** vector search (a small embedding model is fetched once, then cached); set `DAIMON_RAG_BACKEND=tfidf` for an instant, offline scikit-learn backend. It falls back to TF-IDF automatically if chroma can't initialise. Corpora live in `rag/corpus/`: Seneca, Marcus Aurelius, and Nietzsche use genuine **public-domain** text; Camus and Weil (whose translations are still under copyright) use **original thematic notes** — concept summaries, not quotations.

## Commands

| Command | What it does |
|---|---|
| `daimon init` | Create the local store. |
| `daimon write [-p seneca]` | Generate today's letter. |
| `daimon reply [-p seneca]` | Write back. |
| `daimon log [-p seneca]` | Read your correspondence. |
| `daimon salon "<question>" [-p seneca,nietzsche]` | Pose one question to several philosophers. |
| `daimon themes [-p seneca] [--open]` | Build the graph of recurring concepts in your replies. |
| `daimon send [-p seneca] [--dry-run]` | Generate and email the day's letter (Resend). |
| `daimon web` | Launch the web UI. |
| `daimon dbcheck` | Report the storage backend and run a read/write round-trip. |

**Philosophers:** `seneca` · `aurelius` · `nietzsche` · `camus` · `weil`

## Storage & deployment

- **Local / CLI:** a SQLite file (zero setup).
- **Deployed:** point at a free [Turso](https://turso.tech) libSQL database (`TURSO_DATABASE_URL` + `TURSO_AUTH_TOKEN`) so each visitor's letters and philosophy persist across restarts. The data layer is driver-agnostic and falls back to SQLite with a warning if the Turso driver is absent; `GET /api/health` reports the active backend.

Ships as a **Docker app** (port 7860) ready for **Hugging Face Spaces** — see **[DEPLOY.md](DEPLOY.md)** for the full guide (and Render / Fly.io notes). The Groq key is a deploy *secret*, never committed.

## Architecture

```
src/daimon/
  cli.py          # init / write / reply / log / web / salon / themes / send / dbcheck
  api.py          # FastAPI app (letters, reply, salon, prefs, search, bookmarks, stats, health, PWA)
  graph.py        # LangGraph: load_context → planner → drafter(+RAG) → polisher
  salon.py        # parallel fan-out: many philosophers, one question
  about.py        # philosopher profiles (About section)
  llm.py          # Groq (ChatGroq) client
  db.py           # storage: SQLite (local) / Turso libSQL (deploy), driver-agnostic
  limits.py       # per-visitor + global rate limiting
  config.py       # .env loading
  personas/       # seneca, aurelius, nietzsche, camus, weil (+ registry)
  prompts/        # each philosopher's system prompt
  rag/            # retrieval over corpora (chroma | tfidf); corpus/*.txt
  themes/         # concept extraction → networkx graph → pyvis viz (+ Neo4j)
  delivery/       # Resend email + daily cron entrypoint
  web/            # SPA: index.html, styles.css, app.js, three-bg.js + view/feature modules,
                  # sw.js, manifest.webmanifest, icon.svg, portraits/
tests/            # pytest suite (offline)
.github/workflows/  ci.yml  ·  daily-letter.yml
Dockerfile        # Hugging Face Docker Space (port 7860)
```

**Stack:** Python · LangGraph · Groq · FastAPI · Three.js + GSAP · SQLite / Turso · chromadb / scikit-learn · networkx / pyvis / Neo4j · Resend · Docker · GitHub Actions.
